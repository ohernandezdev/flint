Make a bootable USB on your Mac, without risking the wrong disk

Flint writes Windows and Linux installers to a USB stick. Its drive list only shows external, removable drives, so your Mac’s own disk can’t be picked by mistake.

Why it exists

I bought parts for a new PC and needed a Windows installer on a USB stick. All I had was a Mac. The options were paying for one of the few apps that do this, or running an unsigned binary from a site I’d never heard of, as root, pointed at my disks. Neither felt right, so I wrote the one I wanted and made it free. I built it alongside an AI coding agent. That’s what made it realistic for one person to ship it with tests, a properly isolated privileged helper and a notarized release.

Omar Hernandez, who wrote Flint

How it works

Four screens, then you’re done

Flint reads the ISO first and picks how to write it. Windows installers get copied to a FAT32 drive. Linux images get written byte for byte.

  1. 01

    Pick the ISO

    Drop it on the window. Flint checks how the image boots before it touches anything, and tells you what it found.

  2. 02

    Pick the USB drive

    Only external, removable drives show up. Your Mac’s internal disk isn’t hidden behind a filter, it never makes it into the list.

  3. 03

    Confirm

    You see the exact drive name and size, and tick a box that says you understand it will be erased. The button stays off until you do.

  4. 04

    Let it write

    Format, copy, split, finish. Every phase shows real bytes, speed and time left. Linux images skip straight to one raw write.

What it does

A small app with one job

Windows or Linux, it works out which

Flint reads the ISO’s boot records, the MBR signature and El Torito, and picks a method. Windows installers are copied to a FAT32 drive with install.wim split into pieces FAT32 can hold. Linux and other isohybrid images are written raw, the way their makers ship them. Anything it can’t make bootable is turned away before you start.

Win11_25H2_English_x64.isoFAT32 copy · install.wim split to fit
ubuntu-26.04-desktop-amd64.isoraw write · byte for byte

Checks the SHA-256 if you ask

Paste the hash from the download page and Flint checks the file against it, and tells you if it doesn’t match.

Won’t start a write it can’t finish

Before a raw write it checks the stick is at least as big as the ISO, so you never end up with half an image.

Progress you can read

Bytes, percent, MB/s and time left for every phase, the raw write included. No endless spinner.

Warns about Secure Boot

If the ISO’s boot files predate mid-2024, they were likely signed only with Microsoft’s 2011 certificate and may not boot with Secure Boot on. Flint warns you before you start.

Safety

Erasing the wrong disk is the whole risk

Flint erases drives and runs a helper as root. That’s the dangerous part, so these checks sit between you and the wrong disk.

  1. S-1

    Only external drives get listed

    A drive has to be external, physical and removable or ejectable to show up. The boot disk, disk images and virtual devices are dropped in code, before the interface ever sees them. Other external drives, like a backup disk, can appear, so unplug the ones you care about.

  2. S-2

    You confirm by name and size

    The confirm screen shows the exact drive and its size, and the erase button stays off until you tick the box.

  3. S-3

    Checked again right before writing

    The drive is looked up again just before the write, in case the stick changed while the window was open.

  4. S-4

    The helper double-checks

    The root helper checks on its own that the target is external and removable. It doesn’t take the app’s word for it.

  5. S-5

    Failures stop cleanly

    If a step fails, the build stops and tells you what happened instead of carrying on with a half-made drive.

Copying, splitting and verifying run as you. The helper only touches the disk itself: it erases it, and for Linux images it also unmounts it, writes the image and ejects it.

Etcher writes Windows ISOs as raw images, which don’t boot on most PCs, and warns you about it. WinDiskWriter is Windows-only. Boot Camp Assistant doesn’t exist on Apple Silicon, and Intel Macs from 2015 on don’t use a USB stick for it. Flint’s Linux path is newer than its Windows one, see the FAQ.

Questions people ask

Can it erase my Mac’s disk?

No. The drive list only contains external, physical, removable drives. Internal disks, disk images and virtual devices are filtered out in code, and the root helper checks the target again before it writes. Other external drives, like a backup disk, can show up, so unplug the ones you care about before you start.

Why does macOS ask me to approve something in Login Items?

Erasing a disk needs root. Instead of running the whole app as root, Flint installs one small helper through SMAppService that only erases the disk and writes the image. macOS asks you to allow it once, in System Settings → General → Login Items. If you write a Linux ISO that sits in a protected folder like Downloads, macOS may also ask you to give the helper Full Disk Access; Flint links you straight to that setting.

Which ISOs work?

Windows installer ISOs are tested end to end: Windows 11 25H2, including a real install from the stick. Linux and other isohybrid ISOs, such as Ubuntu, Fedora and Debian, are written raw. The detector is tested against Ubuntu 26.04, but booting from a Flint-made Linux stick hasn’t been confirmed on real hardware yet, so reports are welcome. ISOs that can’t be made bootable are rejected before anything is written.

Does it work on Intel Macs?

Partly. Linux images work on both. Windows ISOs whose install.wim is over 4 GiB, which includes current Windows 11 images, need an Apple Silicon Mac for now: the wimlib tool bundled in v1.0.0 is arm64-only, so on an Intel Mac the build fails at the split step, after the drive has already been erased.

Help fix it on GitHub

How big does the USB stick need to be?

16 GB for Windows 11, and Flint warns you below that. For Linux, at least the size of the ISO.

Does it phone home?

No. There is no account, no analytics and no network code in the app. It’s GPLv3, so you can check.
